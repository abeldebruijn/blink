# MVP Is Social-Ready Reading

Blink's MVP is an authenticated social-ready reading product, not a full reader-to-reader social network. The first version focuses on Feed subscription, Initial Import, extracted Reading View, Abstracts, Personal Notes, Tags, Home Feed actions, Read Later, and sharing the original article URL. Social Discovery, public profiles, follows, public Blink post pages, advanced ranking, Daily Refresh, and reprocessing tools are deferred so the product can prove the core feed-to-reading loop first.
